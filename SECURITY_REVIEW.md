# Dependency review — candidate, not a release approval

The initial strict tree resolved 620 physical packages. `npm audit --omit=dev`
reported 14 affected packages (7 high, 7 moderate), stemming from three underlying
advisories. Raw output is in `artifacts/implementation/npm-audit.json`.

| Advisory | Reachability assessment | Downstream compatibility pin |
|---|---|---|
| [Sharp/librsvg](https://github.com/advisories/GHSA-wq5f-xc86-pv6w) | Image decoding is a TUI capability; the shipped official Node and glibc Linux targets make the described decoder issue relevant. | `sharp@0.35.5`, including its matched prebuilt libvips packages |
| [MCP OAuth client](https://github.com/advisories/GHSA-6qxp-vccf-f47h) | HTTP MCP OAuth is an optional user-configured capability. Treat stored OAuth credentials and issuer binding as relevant; stdio alone is outside the affected path. | `@modelcontextprotocol/client@2.2.0` and matching `core@2.2.0` |
| [fflate ZIP64 loop](https://github.com/advisories/GHSA-px8p-9vwx-vf98) | The bundled office conversion dependency carries this parser; optionality does not justify shipping the vulnerable parser. | `fflate@0.8.3` |

These are narrow transitive security overrides. The agreed DSH RC.2 and Chimney
0.15.0 versions are unchanged. A fresh strict install, native imports, and all 29
finished-executable scenarios passed for the local Linux candidate. Its fixed
tree audit on 2026-10-16 reported zero known advisories. Raw audit output is
`artifacts/implementation/npm-audit-fixed.json`. Native CI qualification remains
pending. No audit exemption or `audit fix --force` is used.

No existing credentials are imported or migrated. Optional MCP configuration
must retain issuer information provided by the updated client. The payload must
not include proprietary agent distributions. Native dependency inventory and
third-party notices are generated by the builder. Corresponding sources include
28 native library archives and the 357 registry crates from librsvg's Cargo.lock,
verified against their committed digests. Original native license files and Go
notices are preserved with byte hashes. The release assembly checks source,
notice, payload and finished-binary receipts before publication.
